# Nexus Admin

An E-Commerce Admin Panel built with React, Vite and Tailwind CSS.

## 🔗 Live Demo

[https://johann-2909.github.io/Nexus-Admin/](https://johann-2909.github.io/Nexus-Admin/)

## Features

- Dashboard with KPI statistics and weekly revenue chart
- Product management with full CRUD functionality
- Order management with dynamic status badges
- Multi-page navigation with React Router
- Responsive design with Tailwind CSS

## Tech Stack

- React
- Vite
- Tailwind CSS
- Recharts
- React Router

## Installation

```bash
npm install
npm run dev
```
